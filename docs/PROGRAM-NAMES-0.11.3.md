# 0.11.3 自定义程序名称修复

修复数字或汉字开头的程序名，新建、保存、载入、导出与导入使用相同规则，现有农场无需重开。

- 支持 `123`、`1号农场`、`浇水程序`、`中文_2` 等名称，最多80字符，不填写 `.py`。
- 创建失败时在输入框下显示原因并保留原文；重名、仅大小写不同、规范等价的Unicode名称及系统保留名会被检查。
- 默认名称和模板名称会自动避开已有名称；路径分隔符等非法字符不能进入导出路径。
- 存档读取保留合法旧名称，没有新增长度或保留名规则导致旧存档被丢弃。
- 中文模块直接导入；数字开头的模块可用函数导入或命名空间别名：

```python
import 浇水程序
from 123 import work
import 123 as farm
```

数字开头的程序名与变量名是不同概念，`1abc = 5` 仍属无效变量语法。中文变量、函数及参数名称已与中文模块引用一并支持。
