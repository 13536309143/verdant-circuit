# 0.11.1 开始游玩

本版为全新自动化农场，请使用新开局。F8 切中文，Esc 打开设置。

1. 等草成熟，再运行 `harvest()`；积累干草。
2. 研究循环，创建“第一份收获”模板，运行它持续生产。
3. 研究种植、扩田、运算符、变量及传感器。
4. 用灌木／树获得木材，翻土种胡萝卜，逐步开放南瓜与其他系统。
5. 游戏内手册列出动作、查询、科研、并行与模拟接口。

生产需要相应物资。缺少某种资源时可回到免费草／灌木生产。未解锁的语言功能会提示所需研究；自由练习可在设置开启“允许未解锁语法”。

主工作台运行会重启控制程序。查看其他文件保留执行；浮动窗口可以在数量上限内独立运行。函数完成的工作机消失，`wait_for()` 可以取得返回值。

详见 [中文 README](../README.zh-CN.md) 和 [完整测试手册](TESTING.md)。
