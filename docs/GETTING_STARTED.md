# 禾序 0.10.1 内部测试版

解压 HeXu-macOS-0.10.1.zip，打开 HeXu-0.10.1.app。先在旧版设置中“保存并退出”，避免两个实例同时写入存档。旧存档可继续使用，原有程序保留；新农场默认一个程序。

## 本次可玩内容

- 代码编辑区显示金色光标与蓝色选区。Cmd/Ctrl+Z撤销，Cmd/Ctrl+Shift+Z或Ctrl+Y重做，也可用按钮。每份程序在本次会话内最多100步历史。
- “程序列表”中新增、查看、删除，至少保留一份。查看另一份不会停止当前程序，运行新程序才替换当前执行。运行中的程序先停止再删除。
- 任务采用本任务新增收获数量：稻穗2000、萝卜1000、亚麻1400、蓝莓2400、向日葵1300、南瓜1200、茶1250、星辉花500。没有时间领奖条件；新接任务不计历史收获，科技和程序优化可以加快完成。无加速基准范例约11.5～12.6分钟，详见设计文档。
- 科技路线改为可滚动的节点树，显示前置条件；金币成本3倍、研究点2倍，并增加前置链。已购买科技不回退。
- 8种作物、30份委托、18项研究、6项试炼仍可玩；原先灌溉修复保留，M07使用0.6阈值。
