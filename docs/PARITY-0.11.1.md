## 有意采用自己的规则

- 这是独立重写的同类游戏，不是原作可执行程序的逐像素复制。界面、音画、资源成本曲线、计时和本地竞速预设由本项目定义。
- 语言是 Python 风格子集。支持游戏内说明列出的接口，不执行 Python 标准库或操作系统调用。不支持关键字传参、切片、跨行容器字面量等完整 Python 特性；递归最多 24 层。
- 当前源码的本地资源竞速采用 8×8 中阶预设，各资源生产数量目标不同，达标后须结束程序；模拟 / 竞速上限为一游戏小时，不支持嵌套模拟。没有原作的在线排行榜数据。
- Steam 在线排行榜与 Steam 成就按用户选择留待后续接入，需要禾序自己的 App ID。本版先提供完整的本地记录、竞速和成就。
- 本次重写采用独立函数无人机，移除了 0.10.2 的大型机体、维修费与队列交通模型；浮空岛和未发行的原作采矿扩展不在本版范围。
- 存档保存世界、程序与纪录，不保存正在执行的解释器调用栈。载入后明确点击运行。
- Windows 包在 Mac 上交叉构建，尚未经过 Windows 真机运行验收；Mac 应用尚未签名公证。
