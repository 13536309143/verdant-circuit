# 禾序 0.10.1 内部完整测试操作手册

适用版本：2026-10-29 扩展更新的《禾序 / Verdant Circuit》0.10.1 内容测试版，Unity 2022.3.62f3c1，macOS Intel / Apple Silicon。

这份手册用于测试现有游戏。文中的 `python` 代码块复制到**游戏右侧的自动化工作台**运行，不要放进 Unity C# 脚本；只有第 11 节的 `csharp` 代码需要放进 Unity 工程。农场语言受 Python 启发，但不等同于完整 Python。

建议先在独立应用完成一遍真实操作流程，再在 Unity 中运行自动回归。以下预期结果是验收标准，勾选项留给实际测试者填写，不表示已全部人工验证。

## 1. 测试准备与统一操作

### 1.1 准备一个专用测试存档

1. 完全退出已经运行的《禾序》，停止 Unity 的 Play 模式。**独立应用和 Unity 编辑器不要同时运行游戏**，它们可能共用存档目录。
2. 在 Finder 选择“前往 → 前往文件夹”，输入 `~/Library/Application Support/Fieldworks/禾序/`。如尚未启动过游戏、目录不存在，先启动一次并通过“设置 → 保存并退出”退出。
3. 把整个“禾序”存档文件夹复制一份，命名为“禾序-测试前备份-日期时间”，保存到自己的测试记录目录。不要只依赖会滚动覆盖的 `.bak`。
4. 解压 `HeXu-macOS.zip`，打开 `HeXu.app`。Unity 中测试则打开 `<你的工程目录>`，打开 `Assets/VerdantCircuit/Scenes/VerdantCircuit.unity` 后点击 Play。两条路线选一条。
5. 游戏中选择“设置 → 新建农场 → 备份并开始”，然后在欢迎页点击“开始农耕”。预期为 4×4 农田、120 金币、0 研究点、0 光能；最初有 4 格稻穗，部分已经接近成熟，初始水量会自动恢复，不要求截图时恰好等于 50。
6. 确认速度为 1×。先完成基础操作，再考虑改为 4× / 8× 加速主线。记录本次使用的倍率。
7. 在记录表写下 Mac 型号、芯片、macOS 版本、屏幕分辨率、游戏版本、测试开始时间和使用的是独立应用还是 Unity。

### 1.2 每次替换程序的固定顺序

1. 点击“停止”，确认程序状态已停止。
2. 点击右侧代码编辑区，再按 Cmd+A 选中**编辑区**内的全部代码。
3. 复制本手册指定的完整代码块并粘贴。代码块两端的围栏标记不要复制；缩进为四个空格，使用英文括号、冒号和引号。
4. 点击“运行”，或按 Cmd+Enter。观察机器人、执行行、日志和资源确实推进。
5. 达到本步骤目标后点击“停止”，领取当前委托，再进入下一步。领奖后若下一份委托已经满足，按顺序继续领取，并分别记录结果。
6. 换程序不会重置已有作物。新程序会收获成熟旧作物，再补种新作物；蓝莓还会再生，完全换田可能需要三次收获。

### 1.3 必须知道的当前行为

- 所有主线委托使用**累计指标**，并非接到委托后从零开始。库存用于订单、加工；累计产量用于主线，两者不要混为一谈。
- `count(grain)` 返回稻穗**当前库存**。交付和加工会降低它，但不会倒扣主线累计收获。
- 游戏坐标 `x()` / `y()` 从 0 开始；界面地块编号从 1 开始。
- 移动越界会环绕；邻接加成检查四邻格，当前版本**邻接不跨边界环绕**。
- “暂停”只暂停程序，农作物继续生长。“科技 / 仓库 / 设置”等弹窗打开期间（程序列表除外），农场生长、程序和试炼计时暂停；关闭后继续。
- 程序运行时键盘手动农耕受抑制。编辑代码时快捷键应优先输入文字。
- 单步会执行到下一个动作或本帧指令预算结束，**不是严格执行一行源代码**。
- 倍率同时改变农场与程序的模拟推进速度；试炼限制使用游戏时间。自动保存按真实时间约每 30 秒触发。
- 任一程序达到 500000 条指令会安全停止并提示。长测中遇到该提示，可重新运行；不要直接记为崩溃，但要记录运行时长与提示。
- 科技按钮可以显示但尚未满足章节、前置或资源条件；点击应提示原因并且不扣钱。资源不足时用稻穗巡田恢复收入，停止后再购买。
- 原版 Steam 游戏的 Python 库、`import`、列表、带参数自定义函数、返回值表达式、外部文件与网络访问不属于当前语言功能，不要把它们当作现有支持项。

## 6. 六项独立试炼

### 6.1 每项成功路线

1. 在主线停止程序，“设置 → 立即保存”，记录主线金币、研究、光能、水、格数、当前程序槽、代码和一块代表地块状态。
2. 打开“试炼”，点击本项“开始”。系统会放入对应范例，**进入后计时即开始**；为了测试可达性，直接点击“运行”，不要长时间停留编辑。
3. 观察左侧目标与剩余秒数。打开弹窗会暂停模拟；仅点“暂停”程序则不会暂停试炼计时。
4. 达标后自动恢复主线，程序应停止。原农田和代码应恢复；首次通关增加 400 金币、50 研究，并可能额外触发成就奖励。若要精确核对，先排除同时解锁成就的 +10 研究。
5. 重新打开试炼页，确认星级记录。保存、退出、重启后星级仍在。
6. 再通关同一项，主线不应重复获得首次 400 / 50 奖励；星级仅保留更高成绩。

### 9.2 故意错误与保护

#### E01 缺少冒号

操作：粘贴后运行。预期：第 1 行，冒号或语法错误；程序不应开始。

```python
while True
    harvest()
```

#### E02 两空格缩进

操作：粘贴后运行。预期：第 2 行，缩进必须是四个空格的倍数。

```python
while True:
  harvest()
```

#### E03 除零

操作：粘贴后运行。预期：第 1 行，不能除以零；游戏仍可操作。

```python
print(1 / 0)
```

#### E04 未定义变量

操作：粘贴后运行。预期：第 1 行，未定义变量 missing_value。

```python
print(missing_value)
```

#### E05 零步长 range

操作：粘贴后运行。预期：第 1 行，range() 步长不能为零。

```python
for i in range(0, 5, 0):
    print(i)
```

#### E06 递归深度

操作：粘贴后运行。预期：函数递归超过 24 层；显示发生错误的行号。

```python
def recurse():
    recurse()
recurse()
```

#### E07 未定义函数

操作：粘贴后运行。预期：第 1 行，函数未定义。

```python
missing_function()
```

#### E08 空无限循环

操作：粘贴后运行。预期：界面可响应；可以按“停止”；不应卡住整个应用。

```python
while True:
    pass
```

观察 3–5 秒后点击停止，马上运行 M16，应能恢复正常。若继续放任运行，最终达到 500000 条指令上限安全停止，也属于当前设计。

#### E09 传感器参数错误

操作：粘贴后运行。预期：第 1 行，size() 需要 0 个参数。

```python
print(size(1))
```

#### E10 带参数自定义函数

操作：粘贴后运行。预期：第 1 行，当前函数语法不接受参数。

```python
def tend(value):
    harvest()
```

每个错误出现后，再运行 M16，均应恢复正常；旧错误提示应清除。不要要求错误字句完全相同，但类型、原始行号和安全停止必须正确。E08 没有农场动作，不会推进自动化动作委托。

## 11. 可选：Unity 一键自动回归代码

本节补充规则级自动验证，不能替代上面的鼠标、画面、声音和真人平衡测试。下面代码只创建新的测试农场对象，不给当前玩家农场注入资源；既有 `VerdantChecks.RunAll()` 会在存档目录写独立的 `verdant-verification.json` 测试文件，不覆盖 `verdant-farm.json`。

### 11.1 添加与运行顺序

1. 退出独立应用，停止 Unity Play。
2. 用 Unity 2022.3 打开当前工程或交付的完整工程。
3. 确认有 `Assets/VerdantCircuit/Editor/VerdantChecks.cs`，其中包含 `RunAll()` 与 `Playthrough()`。
4. 在 `Assets/VerdantCircuit/Editor/` 新建 **VerdantInternalTestMenu.cs**，粘贴下方完整 C#。文件必须在 `Editor` 文件夹内。
5. 返回 Unity 等待编译完成，Console 不应出现红色编译错误。
6. 菜单选择 **Tools → 禾序 → 内部测试 → 运行自动回归**。测试期间短暂等待，不重复点击。
7. 通过后会在工程根目录 `InternalTestReports/日期时间/` 生成三份报告，并打开该文件夹。Console 显示完成；任何异常会输出错误并写 `FAILED.txt`。
8. 验收 `01-rules.json` 中 passed=50；`02-campaign.json` 中 contracts=30；`03-trials.txt` 有 6 条通过记录和各自星级。自动通关秒数不是承诺真人游玩时长。
9. 将报告文件夹复制到本次测试档案。测试入口仅用于内部开发，可以保留在 Editor 目录，不会编进玩家运行时代码。

```csharp
using System;
using System.IO;
using System.Text;
using UnityEditor;
using UnityEngine;
using Verdant;

public static class VerdantInternalTestMenu
{
    [MenuItem("Tools/禾序/内部测试/运行自动回归")]
    public static void Run()
    {
        if (EditorApplication.isPlayingOrWillChangePlaymode || EditorApplication.isCompiling)
        {
            Debug.LogWarning("请先停止 Play 并等待编译完成，再运行内部测试。");
            return;
        }

        string folder = Path.GetFullPath(Path.Combine(
            Application.dataPath, "../InternalTestReports",
            DateTime.Now.ToString("yyyyMMdd-HHmmss-fff")));
        Directory.CreateDirectory(folder);

        try
        {
            File.WriteAllText(Path.Combine(folder, "01-rules.json"),
                VerdantChecks.RunAll(), Encoding.UTF8);
            File.WriteAllText(Path.Combine(folder, "02-campaign.json"),
                VerdantChecks.Playthrough(), Encoding.UTF8);

            int[] templates = { 0, 1, 2, 4, 5, 6 };
            var report = new StringBuilder();
            for (int index = 0; index < 6; index++)
            {
                var farm = new VerdantFarm(false, "verdant-internal-trial.json");
                farm.Data.contract = index * 5;
                farm.StartChallenge(index);
                if (!farm.InChallenge)
                    throw new Exception("无法进入试炼：" + index);

                var program = new FarmCompiler().Compile(
                    VerdantContent.Templates[templates[index]]);
                var vm = new FarmVM(farm, program);
                int frames = 0;
                while (farm.InChallenge && frames++ < 100000)
                {
                    for (int budget = 0; budget < 160 && !vm.Finished; budget++)
                        if (vm.Step()) break;
                    farm.Tick(Mathf.Max(0.02f, vm.Wait));
                }
                if (farm.InChallenge || farm.Data.stars[index] == 0)
                    throw new Exception("试炼未通过：" + VerdantContent.ChallengeNames[index]);

                report.AppendLine(VerdantContent.ChallengeNames[index]
                    + " / PASS / " + farm.Data.stars[index] + " stars / "
                    + farm.challengeTime.ToString("F2",
                        System.Globalization.CultureInfo.InvariantCulture)
                    + " game seconds");
            }
            File.WriteAllText(Path.Combine(folder, "03-trials.txt"),
                report.ToString(), Encoding.UTF8);
            Debug.Log("禾序内部自动回归通过。报告：" + folder);
            EditorUtility.RevealInFinder(folder);
        }
        catch (Exception error)
        {
            File.WriteAllText(Path.Combine(folder, "FAILED.txt"),
                error.ToString(), Encoding.UTF8);
            Debug.LogException(error);
            EditorUtility.RevealInFinder(folder);
        }
    }
}
```
