## 人工操作重点

1. 在宇宙选择已解锁地球，先播放降落；一格开局默认近景，应能看见草从幼苗长大，收获后干草增加，出现碎光。
2. 未开放星球和按钮为灰色，分别沿独立随机轴转动。打开宇宙科技购买星球解锁。
3. 科技按宇宙、地球、花卉、海洋、矿物分区；地球旧科技树保留，点击“地球生态”打开专属科技。购买后节点由暗变亮。
4. 在UFO面板选择母舰仓库−1，将水存入母舰，检查实际到港后入库，再从母舰发往其他星球。跨星球航线也应先靠母舰。
5. 取消任务时，未装船的预留退回来源，在途货物完成当前航段并进入到达的仓库；可能位于母舰，不应误判丢失。
6. 用各星球本地产物支付专属科技，核对加工时间和产出确实变化。
7. 按主线项目的明确库存目标生产并交付；后一个目标可能消耗前一个目标的原料，交付前应同时核对全部目标。

## 1. 新开局和首份收入

- 打开 0.11.2，按 F8 切中文。
- 应为一格田、零物资、一个基础无人机，主程序为 `harvest()`。
- 等几秒后运行，干草应增加。提前运行没有产物，等待成熟后仍可再次运行。
- 累计5份干草，研究“循环”，创建“第一份收获”模板，运行后持续产草。
- 研究种植、扩田、运算符、变量、传感器。缺少语法研究应指出所需节点；在设置启用“允许未解锁语法”后可以自由练习。

```python
while True:
    harvest()
```

验收：停止程序时草仍生长；无物资也可以重新生产免费草／灌木，避免永久卡死。

### 科技树与新工作台

- 点击侧边栏“科技”或按 F2，打开“发现之树”。34 个节点分为种植与产能、编程语言、自动化工具三个区域。

- 点击节点，右侧应显示作用、代码示意、等级、前置和当前物资／需求。
- 前置未研究或物资不足时，研究按钮禁用；研究后准确扣费，节点和连线状态更新，画布不重置。
- 用节点名搜索，按回车定位；切换语言后节点名称与详情同步更新。
- 主界面资源卡显示库存，“下一项发现”展示可研究的下一步与资源进度；代码行号应随滚动和修改对齐。
- 检查运行、撤销、重做、独立代码窗口及完成弹窗仍然正常。

## 2. 农田巡查与布局

解锁对应研究后运行：

```python
while True:
    for row in range(get_world_size()):
        for col in range(get_world_size()):
            if can_harvest():
                harvest()
            move(East)
        move(North)
```

- 检查越界环绕和 `get_world_size()` 适配扩田。
- 研究林木，比较密植和棋盘种植的生长速度。
- 点击地块应显示类型、水分、测量值及成熟状态；滚轮缩放。
- 基础机在程序结束后仍可见，已完成的额外工作机消失。

## 3. 语言基础

在允许所需语法后运行；应输出 7、720、12、7、9。

```python
def add(a, b=2):
    return a+b

def factorial(n):
    if n <= 1:
        return 1
    return n*factorial(n-1)

print(add(5))
print(factorial(6))
values=[3,1,2]
values[0]=4
values.append(5)
sum_value=0
for value in values:
    sum_value+=value
print(sum_value)
cost={'hay':3, 'wood':4}
x,y=(cost['hay']+cost['wood'],9)
print(x)
print(y)
```

另测：默认参数、全局变量、嵌套函数、返回函数、元组坐标作为集合／字典键、负索引、break/continue、链式比较、表达式短路。递归过深、无效参数、除零、超限集合应给出错误，并保持界面可响应。

创建 `helpers`：

```python
def double(value):
    return value*2
```

另一个程序：

```python
import helpers
print(helpers.double(7))
```

应输出14。程序语言不是完整 Python，不支持操作系统／标准库导入。

## 4. 巨型南瓜

- 解锁胡萝卜和南瓜，准备种植物资，田地翻土并清除其他作物。
- 载入“巨型南瓜”模板。
- 检查枯死格不能被当作成熟收获；新种植可以替换枯死格。
- 成熟完整方阵应显示为大南瓜；一次收获清除相应方阵并按区域结算。
- 在未完成方阵时提前收获，不能获得整块收益。

## 5. 仙人掌排序

- 准备成熟仙人掌田。
- 分别调用 `measure()` 和 `measure(East)`，记录本格与邻格尺寸。
- `swap(East)` 应真实交换植株。
- 未排序时收获只作用于当前植株。
- 载入“仙人掌排序”模板，完成行列排序后连锁收获整块田。
- 检查收益随连锁数量增加，不能反复收获已经清空的地块。

## 6. 花瓣与能量

- 种植至少10株向日葵，比较花瓣测量值。
- 优先收最大值应有加成；先收较小者会破坏奖励顺序。
- 能量存在时执行加快，动作及代码执行消耗能量。
- 能量耗尽后自动恢复普通速度，不出现负数。

## 7. 伴生、肥料与感染

- 对草、灌木、树或胡萝卜调用 `get_companion()`，按返回类型和坐标安排种植。
- 满足偏好后比较收获；无伴生属性的实体返回 `None`。
- `use_item(Items.Fertilizer)` 增长进度并感染植物。
- 感染收获将部分产出转成奇异物质。
- 对植物使用奇异物质，检查本格及邻格感染翻转；一格田也只应翻转自身一次。

## 8. 迷宫

解锁迷宫，种一丛灌木并准备足够奇异物质：

```python
plant(Entities.Bush)
amount=get_world_size()*2**(num_unlocked(Unlocks.Mazes)-1)
use_item(Items.Weird_Substance,amount)
```

先清理原位置的已有作物；在其他地块种灌木也可生成。

- `can_move()` 应判断墙壁；撞墙移动返回 `False`，坐标不变。
- `measure()` 返回宝藏位置。
- 载入“探索迷宫”模板，4×4、8×8均能找到宝藏并收获。
- 直接在非宝藏处收获会清除迷宫。
- 在宝藏处再次使用对应物资应复用布局、重新放置宝藏，并可能打开捷径。
- 保存／载入后墙、宝藏和复用次数一致。

## 9. 长尾模式

- 准备偶数边长空田和仙人掌库存。
- 运行“长尾覆盖”模板。
- 苹果消耗库存、尾巴增长、不能穿过自身和边界。
- `measure()` 在苹果上报告下一个目标。
- 无法继续移动时模板应安全结束，通过换帽收获骨头；累计产量和竞速统计均增加。
- 同时只能有一台长尾机器。

## 10. 独立无人机

解锁机群，运行：

```python
data=[1]
def worker(n):
    data.append(99)
    return n*2

handle=spawn_drone(worker,7)
if handle != None:
    result=wait_for(handle)
    print(result)
    print(len(data))
```

应输出14和1。确认各机集合隔离、共享农田／库存、可以同格工作，无实体碰撞。

- 达到上限时返回 `None`。
- 完成后 `has_finished(handle)` 为真，仍能取得返回值。
- 主函数结束后未完成的子机继续，全部完成才结束整次执行。
- 已完成工作机释放数量槽，重复生成不会无限积累场景对象。
- “并行分列”模板真实收获；与单机执行比较。

## 11. 代码窗口与调试

- 新增、切换、删除程序，至少保留一个；不能删除正在执行的入口程序。
- 查看另一文件不停止当前运行；主工作台重新运行替换旧任务。
- 打开多个浮动编辑窗口，拖动标题移动，编辑内容应保存。
- 数量允许时浮动窗口可独立运行另一个程序。
- 输入至少20次修改，撤销／重做；新分支清空旧重做。
- 检查光标和拖动选区可见。
- F9 或设置加入断点，命中时所有工作机暂停。
- 单步只推进选中的执行，不放任其他机器继续；恢复后能越过同一断点行。
- 变量观察和悬停应显示当前执行作用域的值。

## 12. 模拟和本地竞速

创建 `experiment`：

```python

    do_a_flip()
```

另一个程序：

```python
a=simulate('experiment', {}, {}, {}, 7, 64)
b=simulate('experiment', {}, {}, {}, 7, 64)

```

应输出 `True`，真实库存、作物与科研不受实验改变。模拟不支持嵌套，并有一小时游戏时间上限。

当前源码的本地资源竞速采用独立的8×8中阶科技开局、固定种子和供应物资，各资源的目标数量在竞速列表中显示；目标是**达到对应新增生产数量并结束所有工作机**。达量但不终止的程序不能完成竞速。最快重置从一格、零物资开始，目标是通过程序解锁本地竞速研究。

- 成功纪录保存最优耗时；较慢成绩不能覆盖最佳。
- 重新启动游戏后纪录和已得成就保留。
- 原作 Steam 排行榜不会被读取或写入。

### 完成弹窗

- 第一次完成成就或成功结束竞速时，应出现“任务已完成”，显示目标名称和竞速耗时。
- 同时达成多个目标应合并提示；点击“知道了”或 Esc 后，同一成就不再弹出。
- “查看纪录”应关闭提示并打开纪录页。
- 打开手册或科技面板时完成目标，应在关闭面板后再提示，不覆盖正在查看的内容。
- 未确认提示时退出／重开，应仍能看见；确认后再重开，不重复提示。
- 切换中英文，弹窗标题、按钮和说明同步切换。弹窗不停止已有自动化程序。

当前平衡与最新实测以 [三小时流程报告](BALANCE-3H.md) 为准。零库存主线测试使用正常科技加速，无额外资源和固定时长门槛；旧全流程报告保留历史数值。


## 16. 0.11.2 分阶段研究验收

1. 新农场即使累积大量干草，扩田2级仍要求林木，3级要求南瓜，4级要求仙人掌，5级要求长尾；不能用调试接口突破未购扩田等级。
2. 对照[手册分级表](MANUAL.zh-CN.md#04--分阶段研究)检查速度及各项增产。缺少对应发现时不能付款；接口 unlock() 返回 False，资源原样保留。
3. 下一作物的累计生产要求显示当前量／目标。花掉资源不能降低已完成的累计生产，不满足产量时单有库存也不能研究。
4. 检查 get_unlock_requirements()、can_unlock()、num_produced() 与科技树一致；满级时下一价格和门槛返回 None。
5. 标准新开局关闭未解锁语法、运行倍率1×；记录全部120次付费研究及34节点满级时间。实际编辑、思考和独立竞速时钟另计。

## 17. 程序卡片和手册验收

1. 创建至少5个程序，程序库显示准确总数和两列卡片；主工作台顶部也可打开程序库并查看活跃数。
2. 运行一个持续生产程序，再打开另一文件：旧文件绿色运行标记保留，新文件琥珀边框表示编辑。暂停后仍算活跃，显示暂停；停止后回到空闲。
3. 从浮动窗口独立运行第二个程序（先解锁容量），两个卡片都显示活跃工作机；关闭编辑窗口不停止执行。
4. 活跃程序不能删除，至少保留一个文件。删除其他文件后数量和选择正确，当前代码不丢失。
5. 手册16章节可切换、搜索；接口速查包含新增三个接口。长正文和代码可滚动且不被裁切，中英文切换后标题、内容和查询状态正常。
6. 资源竞速仍限一游戏小时，最快重置现限四小时；旧规则成绩与当前规则分别保存。


## 18. 0.11.3 自定义程序名称修复

- 分别创建 `123`、`1号农场` 和 `浇水程序`，应成功选中，卡片名称、主编辑器和保存文件保持一致。

- 导出后应有 `123.py`、`浇水程序.py`；新增 `2号外部程序.py` 后导入应保留名称和代码，重启或载入后仍在。
- 中文模块 `import 浇水程序`、数字模块 `from 123 import work`／`import 123 as farm` 应可实际调用。变量本身仍不能以数字开头。
