# Verdant Circuit v0.11.3 — Program Name Fix

Fixes custom program names without changing the staged progression or economy introduced in v0.11.2. Existing farms and programs continue to work; no restart is required.

- Create names beginning with digits or Chinese characters: `123`, `1号农场`, `浇水程序`.
- Keep the same names through save/load, program cards, floating editors, external `.py` export/import, module lookup and simulations.
- Display validation errors below the input and preserve the typed text. Suggest an unused default name.
- Normalize equivalent Unicode names and reject case-only duplicates or reserved filenames to prevent export collisions.
- Support Chinese module references and Unicode identifiers. Numeric modules can use `from 123 import work` or `import 123 as farm`.

Names use letters, Chinese characters, digits or underscores, up to 80 characters; omit `.py`. Variables themselves still cannot begin with a digit.

244 model/language/progression/name checks passed, including 35 targeted name cases. Real-frame UI tests cover creation through the actual Create button, visible errors, preserved input, Unicode filenames, external imports and save/reload. A full zero-inventory replay verifies that the complete research, achievements and competition route still works. Both platform builds report zero errors/warnings.
