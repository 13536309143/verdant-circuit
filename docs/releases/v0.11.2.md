# Verdant Circuit v0.11.2 — Staged Discovery

A staged programming-farm campaign: discover crops, open the next field and production tiers, and build toward a fully automated garden. This public playtest release includes the Discovery Studio interface and the updates made since v0.11.1. Earlier releases remain available.

## What's new

- **About three hours of fresh-farm progression.** Crop discoveries gate individual field, execution-speed and yield levels. Expansion follows Planting 2×2 → Trees 4×4 → Pumpkins 8×8 → Cacti 16×16 → Tail exploration 32×32. Resource prices and cumulative-production goals replace unrestricted early upgrades; no certification timer was added.
- **Program cards.** Two-column file cards, total/active counts, worker counts, green running states, amber editing borders and paused/idle labels. Browsing preserves running work. Active programs cannot be deleted, and at least one file is retained. Floating editors show live status.
- **A full bilingual field manual.** 16 searchable chapters and 33 API groups covering the language, staged research, crop supply chains, water/infection, pumpkin repair, sunflower priority, companions, cactus sorting, maze DFS, tail routes, drones, experiments and troubleshooting. English/Chinese Markdown editions are included.
- **Research APIs.** `get_unlock_requirements()`, `can_unlock()` and `num_produced()` expose the same discovery, production and funding rules used by the tree. Paid research refuses unmet requirements without deducting resources.
- **Balanced production.** Research-gated companion bonuses, bounded cactus/tail multipliers, proportional merged infection, consistent fertilizer maturity checks, meaningful maze routes and resource-specific mid-tier races. Historical race scores stay separate; Fastest Reset now permits four game hours for the staged campaign.
- **Discovery Studio polish.** Connected cultivation/language/tool research tree with pan, zoom and search; completion notices; saved continuous volume slider; code line numbers, undo/redo, external files and independent farm profiles.

## Measured progression and validation

Three actual-interpreter runs started from one plot, zero inventory and ordinary language gates. All research completed in **2h56m–2h59m**; including maze-reuse and 32-worker verification, main-world clocks were **2h59m–3h02m**. Each run paid for all 120 levels across 34 nodes, earned 13 achievements and passed 16 local competition categories. All 360 purchase deductions and staged gates were checked.

The benchmark excludes player editing/thinking and uses normal in-game research/power bonuses. Races and simulations have independent clocks; replayable modes add playtime. It is not a promise that every player finishes in exactly three hours.

209 model/language/progression checks passed, alongside real-frame UI checks for both languages, program cards, preserved running state, paused/deletion behavior, the manual, research tree, completion notices, volume, profiles and external files. Mac Universal and Windows x64 Mono builds report zero errors and warnings. Complete timings, scripts, ledgers and checkpoints are in the test-evidence archive.

## Download and run

- **Mac:** extract `HeXu-macOS-0.11.2.zip`, open `HeXu-0.11.2.app` (Intel and Apple Silicon).
- **Windows x64:** extract the entire `HeXu-Windows-x64-0.11.2.zip` and open `HeXu.exe`. Keep the data folder, UnityPlayer.dll and Mono runtime beside it.
- **Source:** open `HeXu-UnityProject-0.11.2.zip` in Unity **2022.3.62f3c1**, matching the project version. Platform modules are needed to build.
- **Test evidence:** `HeXu-TestEvidence-0.11.2.zip` includes three runs, programs, phase saves, cost/gate ledgers, tested sources and regression reports.
- Verify the four archives with `SHA256SUMS-0.11.2.txt`.

No Unity installation or server is needed to play. The Mac app is not distribution-signed/notarized. Windows is cross-built on Mac and awaits native Windows acceptance. Steam online leaderboards/achievements remain deferred; local records are available.

## Saves and language

Updating from v0.11.1 retains code, inventory and purchased research. Old resources are not reclaimed and purchased tiers are not relocked: **create a new farm for the full staged three-hour campaign**. v0.10.x saves use an earlier format and are not migrated. English is the default; use Settings or F8 for Simplified Chinese.
