# Verdant Circuit v0.10.2 — Fleets & Languages

A playable fleet update with independent capacity/airframe progression, a rebalanced economy, and English/Simplified Chinese support. v0.10.1 remains unchanged and available.

## Playable additions

- Capacity research: **1 → 2 → 4 → 8** drones, saved separately from footprint tier.
- Airframes: **1×1, 2×2, 3×2, 2×3, 3×3** with rectangular occupancy and per-cell production costs/yields.
- General, irrigation and harvesting drones; stable IDs, deployment, resizing and retirement through Fleet (**F7**) or code.
- One controller VM with concurrent per-drone queues, up to 64 jobs each. Full-footprint routes wait for occupied space; blocked jobs expire after 30 game seconds for replanning.
- Capped direct-collision repair fees and active-only upkeep. No negative upkeep debt; base drone and free grain remain a recovery path.
- Eight new research projects (26 total), two fleet templates (11 total), actual deployment/resize prices in the UI.
- Harvest coin/research values and order bonus rebalanced; all 30 campaign contracts still pass deterministic replay.

## Languages and downloads

The game defaults to **English**. Select Simplified Chinese in Settings → Language, or press **F8**; the choice persists. Player-authored code is unchanged. README is English-first with a Chinese edition.

- **Mac:** extract `HeXu-macOS-0.10.2.zip`, open `HeXu-0.10.2.app` (Intel + Apple Silicon).
- **Windows x64:** extract the complete `HeXu-Windows-x64-0.10.2.zip` folder, run `HeXu.exe`. Keep the data folder, UnityPlayer.dll and Mono runtime together.
- **Develop:** open `HeXu-UnityProject-0.10.2.zip` with Unity 2022.3.62f3c1; install the relevant platform build module. Build scripts and pinned Localization/Addressables dependencies are included.
- Check downloads with `SHA256SUMS-0.10.2.txt`.

Save and quit an older game before upgrading. Existing progress/programs are preserved; old saves receive a base 1×1 drone, and new fleet research must be earned. Saved queues resume paused for explicit review. Settings shows the actual save location.

## Verification and limits

**45 fleet checks**, **50 core checks**, all **30 contracts**, all **11 templates**, **1,216 localized table entries** with no gaps, and real Play-mode checks for advancing frames, UI raycasts, both languages and completed irrigation queues. Both platform builds report **0 errors / 0 warnings**. Mac standalone startup and language switching were checked.

This is a public test release. Windows was cross-built on Mac and has not yet been run on native Windows hardware. The Mac package is not distribution-signed or notarized. Local pathfinding does not solve every packed traffic layout; leave lanes and replan blocked jobs. Floating islands and inter-island logistics are future work. Automated replay is not a claim of final human balance or compatibility across all hardware.
