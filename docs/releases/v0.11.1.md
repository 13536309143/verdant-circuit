# Verdant Circuit v0.11.1 — The Automation Rebuild

Start a new farm: this release replaces the former contract economy, interpreter and saves with a fresh resource-driven automation game. v0.10.1 and v0.10.2 remain available.

- 33 research nodes funded by production; grass, trees, carrots and advanced crop algorithms.
- Giant pumpkins, dead-plant repair, sunflower priorities, cactus sorting, random companions and infection.
- Connected reusable mazes, treasure and an apple-and-tail mode.
- Independent function drones with isolated state, returned results and waiting handles.
- Functions, recursion, closures, modules, lists, tuples, dictionaries and sets in a Python-inspired language.
- Multiple code windows, 100-state undo/redo, pause/step, breakpoints, variable watch/hover and external-editor files.
- Seeded simulations, local resource races, records, 13 local achievements and independent farm profiles.
- English default; Simplified Chinese via Settings or F8.

## Downloads

- **Mac:** extract `HeXu-macOS-0.11.1.zip`, open `HeXu-0.11.1.app` (Intel + Apple Silicon).
- **Windows x64:** extract the entire `HeXu-Windows-x64-0.11.1.zip`, open `HeXu.exe`; keep its accompanying folders and libraries.
- **Source:** open `HeXu-UnityProject-0.11.1.zip` in Unity 2022.3.62f3c1. Relevant platform modules are required to build.
- Verify archives with `SHA256SUMS-0.11.1.txt`.

## Test status and scope

This is a public test release. 39 farm/runtime checks, 9 language checks, 1,680 localized entries with zero gaps, and real-frame bilingual, multi-drone, profile, floating-window and external-file checks are included in the repository reports. Both platform builds report 0 errors / 0 warnings. Mac standalone startup, code editing/execution, undo/redo and language switching were checked. Build reports are included. Windows is cross-built on Mac; native Windows verification remains outstanding. The Mac app is not distribution-signed or notarized.

This is an independent implementation with its own code, visuals, sounds, economy and race presets. The language is a documented Python-style subset. Local races target 1,000 newly produced units followed by program termination; simulation/race sessions are bounded to one game hour. Steam online services are deferred. Old large-body traffic systems, floating islands and the mining expansion are outside this release. Old saves are not migrated.
