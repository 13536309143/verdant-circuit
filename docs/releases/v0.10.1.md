# 禾序 v0.10.1 · 首次公开测试发行

一款用循环、条件与函数驱动机器人的单人编程农场游戏。

## 下载

- **HeXu-macOS-0.10.1.zip**：可直接游玩的 macOS 通用应用，包含 Intel x86_64 与 Apple Silicon arm64。解压后打开 HeXu-0.10.1.app。
- **HeXu-UnityProject-0.10.1.zip**：与 v0.10.1 标签对应的 Unity 工程、README、文档和构建工具。以 Unity 2022.3.62f3c1 打开。
- **SHA256SUMS.txt**：两个发行附件的 SHA-256 校验值。

## 本版内容

- 8 种作物、30 份主线委托、18 项科技、12 项成就。
- 6 项独立试炼、5 种加工配方、3 个持续更新的订单槽。
- 代码工作台修复光标与选区，支持每份程序100步会话撤销/重做。
- 程序列表可增删，至少保留一个；查看其他程序不中断当前执行，运行新程序才替换VM。
- 科技节点树与增强的前置关系；不同作物采用不同的任务新增收获数量，取消固定600秒认证。
- 自动保存、备份和恢复。

## 试玩

方向键/WASD移动，空格播种，E收获。将 README 的稻穗巡田示例粘贴到右侧，点击运行；完成任务后领取奖励。Cmd/Ctrl+Z撤销，Cmd/Ctrl+Shift+Z或Ctrl+Y重做。完整说明见仓库 README 和 docs/TESTING.md。

## 升级与边界

旧版先“设置 → 保存并退出”再打开新版，不要同时运行多个实例。已有程序与已领取的委托保留；新接的作物任务按新增收获计算。

本包为公开测试版，尚未进行 Apple 发行签名与公证、跨机兼容矩阵和长期真人平衡测试。Windows、Linux、WebGL 和 Steam 版本未提供。多无人机与浮空岛目前是设计及独立规则原型，未接入可玩场景。

## 验证

50项游戏规则检查、30份主线回放、6项试炼范例通过；编辑器和程序管理完成事件与画面检查。群岛/机群原型通过24项规则检查。验证记录见 docs/reports/；这些结果不能代替真人长期试玩。
