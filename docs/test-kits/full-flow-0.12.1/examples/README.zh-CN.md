# 自主群岛子程序（可选）

这6个文件提供另一种架构：总控只启动各机，随后结束；抽水、谷物、采矿／冶炼和循环货运各自独立判断库存并工作，不依赖18单规划器。

适用于已开放前三岛、研究相应语言、并有足够机队资金的测试农场。先全部停止，再拆解不需要的旧机体，留出至少4个槽位。将本目录6个 `.py` 一起导入同一农场，运行 `local_master`。它会正常付费研究数量与工程类型，建造4台1×1机体，绑定不同子程序；当前槽位／空间／研究不足时会明确输出错误，不赠资源。

- `local_water`：苇泽抽水，库存上限400。
- `local_grain`：炉心有水时种谷物，库存上限200。
- `local_forge`：缺矿先采矿，原料齐备才炼合金，库存上限200。
- `local_cargo`：水库→炉心送水、炉心→工坊送粮、水库→工坊送水，轮询路线避免饿死一条支线。
- `local_common`：共享单机查询函数；每个解释器导入自己的模块状态。
- `local_master`：启动后即可结束；你可在主编辑器查看或运行其他代码，4台实体机继续工作。

观察三岛库存出现水、谷物、矿石和合金。此例不会自动交订单，便于你自行修改生产策略、绑定不同子程序，再和总控订单模式比较。停止代码与取消物理队列是两种动作，整体接管请使用全部停止。
