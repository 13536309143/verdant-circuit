## 02 / 球面坐标

地球就是原有农场的球面版本，不是额外花园。扩展依次为1×1、2×2、4×4、8×8、16×16、32×32、64×64、128×128、256×128、360×128。每格占1°。完整纬度范围为南纬64°至北纬64°，两极不可用。只有横向360列全开才环绕，纵向从不环绕。扩展会居中保留旧地块和作物，局部坐标相应重新编号，请扩展后重读坐标。宽高分别查询。

```python
width = get_world_width()
height = get_world_height()
```

## 05 / 类Python语言

游戏解释器是明确记录的Python子集，不是系统Python。支持循环、条件、函数、闭包、默认值、位置参数、集合、模块和返回值；不提供操作系统、文件、网络、标准库访问，也不支持异常捕获与关键字参数。新增sum、enumerate、zip、sorted、reversed、round、all、any、pow、divmod、type、Unicode和字符串方法，逐项见接口说明。集合操作返回快照列表，而非Python惰性迭代器或视图；数值使用统一表示。

```python
for index, value in enumerate([10, 20], 1):
    print(index, value)
```

## 07 / 本地载具与机体

地球是无人机，芳华是小蜜蜂，沧澜是渔船，鎏金是采矿无人机，均不能跨星球。各星球有独立slotTier数量和hullTier尺寸变量，分别付费研究。1×1、2×1、2×2、3×2、3×3占据真实格子，必须能放进已开放范围；路径检查完整占地，拥堵时等待。蜜蜂扇翅、无人机转旋翼、渔船转推进器、矿机转钻头。

## 15 / 地球与Python函数全集

以下逐项介绍原有地球函数与类Python工具，包括默认参数、返回值和示例。名称区分大小写，不支持关键字参数。get_world_size只是兼容宽度查询，不代表矩形高度。

### `harvest()`

收获脚下成熟作物。南瓜、仙人掌可能触发区域收获；在迷宫宝藏上获得金币。

**参数**: 无参数。

**返回值**: bool：成功为True，未成熟或空地为False。

**使用条件**: 绑定地球农务机；第一格草无需科技。

**失败与边界**: 参数个数、类型错误会停止调用程序；返回False表示条件未满足。

```python
harvest()
```

### `can_harvest()`

只检查脚下成熟情况，不消耗收获动作。

**参数**: 无参数。

**返回值**: bool：可以收获返回True。

**使用条件**: 地球农务机。

**失败与边界**: 参数个数、类型错误会停止调用程序；返回False表示条件未满足。

```python
if can_harvest():
    harvest()
```

### `plant(entity)`

在空地或死亡南瓜上种植；草、灌木、树在草地，胡萝卜等需要耕地。

**参数**: entity：Entities中的作物枚举；大小写敏感。

**返回值**: bool：种植成功True；占用、缺种子、地面不符返回False，不额外扣费。

**使用条件**: 地球农务机；对应种植科技。

**失败与边界**: 参数个数、类型错误会停止调用程序；返回False表示条件未满足。

```python
if get_entity_type() == None:

**参数**: direction：North、East、South或West，不要加引号。

**返回值**: bool：移动成功True。

**使用条件**: 地球农务机。

**失败与边界**: 参数个数、类型错误会停止调用程序；返回False表示条件未满足。

# Bounded latitude rows: sweep east, then return west at each row.
while True:
    for y in range(get_world_height()):
        for x in range(get_world_width()):
            if can_harvest():
                harvest()
            if x + 1 < get_world_width():
                move(East)
        for x in range(get_world_width() - 1):
            move(West)
        if y + 1 < get_world_height():
            move(North)
    for y in range(get_world_height() - 1):
        move(South)

```
