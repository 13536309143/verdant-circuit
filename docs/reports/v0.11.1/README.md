- `language.json`: 9 interpreter checks.
- `classic.json`: 39 farm/runtime checks, including all 9 shipped examples compiling and actual cactus / maze / tail examples completing.
- `playmode.json`: real advancing frames, first harvest, independent workers, both locales, farm profiles, floating windows and external code files. The test source also checks UI raycast/pointer routing and rejection of the Escape control character.

Reports are generated by Unity 2022.3.62f3c1. Test sources are under `Assets/VerdantCircuit/Editor/`. Windows x64 is cross-built on Mac and has not been tested on native Windows hardware. Mac is Universal and is not distribution-signed or notarized. Automated checks do not establish long-term balance, complete Python compatibility or behavior of every possible user program.

Mac 的桌面自动化鼠标点击不能稳定触发 Unity 控件，因此不据此宣称完成真人鼠标验收；按钮路由另由引擎中的 UI 射线与指针派发检查覆盖。请按 [内部验收手册](../../TESTING.md) 再做实际设备验收。
